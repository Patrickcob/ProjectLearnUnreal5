# ProjectLearnUnreal5
Project to Learn Unreal 5 in a c++ centric approach

- Concept learned:
  - Custom implementation of a Gameplay Ability System highly inspired by Unreal's GAS
  - Implementation of Gameplay Elements like Abilities, Attributes, Effects and Tags
  - Exploration of Class reflection and dynamic class loading
  - Implement C++ for Blueprint scripting
  - Input mapping and handling
  - Implementation of a custom UI system using UMG
